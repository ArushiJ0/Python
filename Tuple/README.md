# Tuples

- Immutable - cannot change the elements
- similar to list in other ways

### Packing & Unpacking Tuples -

Tuple can be formed by :

Var = 1, 2, 3

This is packed in a tuple. Now, to unpack this we assign three variables 

a,b,c = var 

We can also use * to unpack in from of groups  

### Key Takeaways -

- Conversion of tuple to list or vice versa can be done. If we need to make changes to the tuple convert it to list, make changes then convert it back to tuple
