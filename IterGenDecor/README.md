# Python Advanced

### Iterators -

syntax : var_name = iter(text)

To access the elements of the iterators next(var_name) is used so the next element in the list is printed 

### Generators -

Used to process one line at a time without loading the whole file into memory

yield keyword is used, n values can be returned and the program doesn’t end

For generator expression () brackets are used instead of [] for list comprehension. This does not generate all values together
