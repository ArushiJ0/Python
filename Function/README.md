### Parameters

- **Default Parameter -** Given a default value when no parameter is given by the user, so it doesn’t show any error.
- **Positional Argument** - Used when there are many parameter represented by (*args).
- **Keyword Argument** - Used for key value pair (accessing dictionaries)  represented by (**kwargs)
- Positional & Keyword arguments can be used together.

### Key Takeaways -

- not any is used when we need to check if no true values are there
