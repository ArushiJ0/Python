# Inheritance

- Syntax - class_name(parent_class_name):
- It uses super() keyword which inherits the attributes of the parent class. super().__init__(attribute_names)
- The child class also inherits the method of parent class
- In multiple inheritance we can inherit from more than one base class. We use base class name instead of super to define which class referring to.
- super() is only used when there is __init__ in parent class
