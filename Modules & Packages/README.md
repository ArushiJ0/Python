# Modules & Packages

- Module is a single file whereas package is folder of files
- Syntax - from package_name import module_name or from module_name import function_name
- Both function and module can imported.
- When **from** is used no need to use package name as a prefix directly apply the functions.
- When custom package is made __ init __.py is a special  file placed inside a folder to indicate that the folder is a package.
