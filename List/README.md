# Lists

- Mutable(can make changes)
- contains different data types

## List Comprehension

Syntax - [expression for var in iteration condition]

Nested syntax - [expression for var1 in iteration for var2 in iteration ]

### Zip Function

Used to combine two or more lists 
Syntax - zip(List1, List2)

### Key Takeaways -

- For random variables random library is imported
- .sort() changes the current list & sorted makes a new list
- (reverse = True) is used for descending order
