# Dictionaries

- Unordered
- Key value pairs
- Keys should be unique
- Dictionary is mutable

### Dictionary Methods -

- .get() - used to access the elements in the dictionary
- del is used to remove a key

### Key Takeaway -

- Shallow copy .copy() is used to make a copy, this allocates a new memory to the copy so the changes made are not reflected in both
- To merge dictionaries ** is used
